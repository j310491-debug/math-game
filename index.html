⚖️ 什麼是「等量公理」？

想像方程式就像一個「平衡的天平」。如果天平的左右兩盤重量相等，那麼只要對兩邊「同時做相同的動作」，天平依然會保持平衡！

1. 等量加法公理 (兩邊同時 ＋) 如果 \( a = b \)，那麼 \( a + c = b + c \)。
例：\( x - 5 = 12 \implies \) 兩邊同時 \( + 5 \implies x = 17 \)。
2. 等量減法公理 (兩邊同時 －) 如果 \( a = b \)，那麼 \( a - c = b - c \)。
例：\( x + 8 = 20 \implies \) 兩邊同時 \( - 8 \implies x = 12 \)。
3. 等量乘法公理 (兩邊同時 ×) 如果 \( a = b \)，那麼 \( a \times c = b \times c \)。
例：\( \frac{x}{3} = 5 \implies \) 兩邊同時 \( \times 3 \implies x = 15 \)。
4. 等量除法公理 (兩邊同時 ÷) 如果 \( a = b \) 且 \( c \neq 0 \)，那麼 \( a \div c = b \div c \)。
例：\( 4x = 28 \implies \) 兩邊同時 \( \div 4 \implies x = 7 \)。
